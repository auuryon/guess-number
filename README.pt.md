# Jogo de Adivinhação de Números

É um jogo baseado em linha de comando, onde o computador seleciona um número aleatoriamente e o usuário precisa adivinhar. O usuário terá um número limitado de tentativas para adivinhar o número. Se o usuário acertar, o jogo termina e ele ganha. Caso contrário, o jogo continua até que o usuário fique sem tentativas.
